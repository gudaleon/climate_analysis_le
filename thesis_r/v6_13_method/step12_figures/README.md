# Figures

- `OBS_JFM.R`: observed Jan-Mar monthly upper-quartile boxplots, Historical vs Present (`Rscript OBS_JFM.R <Station> <temperature model>`).
- `OBS_JJAS.R`: observed Jun-Sep monthly upper-quartile boxplots, Historical vs Present.
- `GCM_hp_JFM.R`: reference models (BCC precipitation, NorESM/EC temperature) Jan-Mar, Historical vs Present.
- `GCM_hp_JJAS.R`: reference models Jun-Sep, Historical vs Present.
- `GCM_nf_JFM.R`: reference models Jan-Mar, Near vs Far future.
- `GCM_nf_JJAS.R`: reference models Jun-Sep, Near vs Far future.
- `run_figures_monthly.R`: runs the six scripts above for all three stations into `output/figures_monthly` (6.13 Figures 2-7 and D1-D12, v7 Figures 3-8 and E1-E12).
- `boxplots_four_periods.R`: the 36 four-period boxplot figures of the annual indices (v7 Appendix F, F1-F36) into `output/figures_boxplots`.
